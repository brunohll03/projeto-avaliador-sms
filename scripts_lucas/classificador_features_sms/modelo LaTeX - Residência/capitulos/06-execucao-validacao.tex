\section{Execução, evidências e limites}
\subsection{Preparação do ambiente}
Os comandos Python abaixo partem da raiz \textit{Residência Tecnológica - IA}, e não desta pasta LaTeX. São necessários Python 3.10 ou superior e Java 17 ou superior. O ambiente virtual mantém as dependências separadas de outros projetos.

\begin{codigofonte}[Instalação na raiz do projeto]
python3 -m venv classificador_features_sms/features_bibliotecas/.venv
source classificador_features_sms/features_bibliotecas/.venv/bin/activate
python -m pip install -r classificador_features_sms/features_bibliotecas/requirements.txt
java -version
\end{codigofonte}

\begin{codigofonte}[Classificação e testes]
python -m classificador_features_sms.features_bibliotecas.main --detalhes 'Informe sua senha.'
python -m unittest classificador_features_sms.features_bibliotecas.test_bibliotecas -v
python -m classificador_features_sms.features_bibliotecas.avaliar_exemplos > avaliacao_exemplos.json
\end{codigofonte}

A primeira inferência pode baixar pesos e tokenizador. A primeira revisão de escrita pode baixar LanguageTool. Depois de disponíveis os recursos, o processamento é local: o modelo executa no dispositivo configurado e o corretor atende em um servidor Java local. A flag de carregamento local do NLI não prepara o cache de Java automaticamente.

\subsection{Uso por outro programa}
\begin{codigofonte}[Instância explícita e encerramento do corretor]
from classificador_features_sms.features_bibliotecas import (
    ClassificadorFeatures, Configuracao,
)

config = Configuracao(limiar=0.70)
with ClassificadorFeatures(config) as classificador:
    resultado = classificador.analisar_sms(
        "Informe sua senha."
    )
    print(resultado["features"])
    print(resultado["detalhes"]["semanticas"]["solicita_senha"])
\end{codigofonte}

\subsection{Como interpretar o JSON}
\termotecnico{features} contém as 24 decisões. \termotecnico{detalhes.semanticas} associa cada feature NLI ao escore, limiar, hipótese e valor. \termotecnico{detalhes.urls}, \termotecnico{telefones} e \termotecnico{erros\_\allowbreak{}detectados} fornecem evidências dos extratores. A configuração registra modelo, revisão solicitada, revisão carregada, versão de LanguageTool e idioma do corretor.

Um escore NLI explica a comparação numérica com o limiar, mas não localiza automaticamente o trecho responsável pela decisão. Já a extração de URL e os erros gramaticais incluem posições. Não se deve apresentar o escore como uma justificativa linguística completa.

\subsection{Diferenças frente à implementação anterior}
A análise semântica passou de regras manuais para comparação NLI. Carga emocional deixou de ser proporção de palavras de um léxico; agora é escore semântico. A revisão de escrita usa regras e dicionário do LanguageTool, o que amplia a cobertura e também altera os falsos positivos. Telefonia usa metadados da biblioteca; URLs usam um extrator especializado; PIX continua sendo uma menção literal, com URLs mascaradas.

Para comparar versões em um dataset, registre qual método produziu cada coluna. Mesmo nome de feature não garante decisões equivalentes entre implementações.
